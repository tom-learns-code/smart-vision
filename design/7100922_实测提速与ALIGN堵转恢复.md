# 7100922 实测提速与 ALIGN 堵转恢复

## 1. 修改背景

7100921 的实车日志显示“速度没有明显提高，并且中途突然停车”。本轮先对完整串口日志做阶段统计和故障定位，再修改代码，没有调整 PID、速度档位或机械参数。

日志统计：

- `RUN_TIME` 共 357 行。
- `adaptive_settle_enabled=1` 共 45 行。
- `adaptive_settle_used=1` 共 0 行。
- `strict_position=1` 共 291 行。

因此，7100921 的自适应停车虽然在普通步骤中被允许，但实车上一次都没有真正提前结束。大部分路径还处于箱子、炸弹、目标点邻域或环境切换上下文，必须继续使用严格策略。

## 2. 根因

### 2.1 自适应停车从未生效

7100921 把三个位置环误差也作为“车辆已经静止”的必要条件。停车保持航向时，位置环目标与误差仍可能继续积累；日志中可见编码器速度和陀螺仪已经接近 0，但位置误差仍然较大。因此 `stationary_ready` 始终不能成立，普通步骤仍完整等待 500 ms。

### 2.2 无新视觉帧计时起点错误

视觉稳定阶段原来用“本轮稳定确认开始时刻”判断 500 ms 无帧，而不是用“最后一帧唯一新视觉帧的到达时刻”。实车故障前已经收到 2 帧有效新帧，但确认阶段总时长达到 520 ms 后仍被错误判为无帧并回退。

### 2.3 突然停车来自短距 ALIGN 堵转

故障发生在：

- `action=14/28`
- `wp=1/4`
- 逻辑步 `23/37`
- 从 `(12,10)` 到 `(13,10)`
- 上下文为 `BOX_NEAR_PRECISE`，`strict=1`，`transition=1`

主 200 mm 网格移动已完成。随后视觉给出约 `(20,-40) mm` 的残差，系统启动严格短距 ALIGN。ALIGN 的轮速/PWM命令已经输出，但编码器约 1 秒内没有形成 5 mm 有效进度，于是点对点层产生 `STALL`。7100921 将 ALIGN 的 STALL 与主体运动 STALL 一样升级为任务硬故障，所以整车上锁。

## 3. 7100922 修改

### 3.1 静止判断改为真实运动量

普通非严格平移步骤只使用以下量判断是否静止：

- 三个编码器速度绝对值均不大于 12。
- IMU Z 轴角速度绝对值不大于 3 deg/s。
- 连续稳定 100 ms。
- 停车至少已经持续 300 ms。

不再使用位置环误差作为静止条件。500 ms 仍是绝对停车上限。

### 3.2 修正视觉无新帧语义

新增最后一帧唯一视觉帧的接收时刻。只有从最后一帧唯一新帧开始连续 500 ms 没有更新时，才允许进入无帧回退。每次 `frame_id` 更新都会重新开始计时。

### 3.3 普通开放步骤缩短视觉确认

仅对 `adaptive_settle=1` 的普通非严格、非切换步骤使用：

- 排空等待 700 ms。
- 稳定帧数 4 帧。
- 最小稳定时间 150 ms。

严格上下文保持：

- 排空等待 1000 ms。
- 稳定帧数 6 帧。
- 最小稳定时间 200 ms。
- 物体邻域单轴 20 mm、合成 30 mm、最多 3 次物理 ALIGN。

### 3.4 ALIGN 堵转改为软恢复

只有短距 ALIGN 发生 `STALL` 时，系统执行：

1. 立即锁电机。
2. 回到视觉稳定等待。
3. 用新的稳定视觉位置重新计算残差。
4. 在既有 ALIGN 次数范围内重试。
5. 次数耗尽后请求重规划，而不是立即把整个任务置为硬故障。

主体网格运动的 `STALL`、越程和其他真实控制故障仍是硬故障，保护没有删除。遥测 `RUN_VIS` 新增 `stall_retry`。

## 6. 实车验收

完整重新上电后执行：

```text
1 -> 等待 FULL_MAP received 和 MAP_END
-> 2 -> D -> 确认 PLAN_SUMMARY valid=1/current=1 与 PLAN_CHECK ok=1
-> B -> 3 -> E -> 等待开局格心复核进入 STEP_WAIT
-> N -> 等待 STEP_WAIT -> N -> 等待 STEP_WAIT -> N
```

重点观察：

- 普通开放步骤应出现 `adaptive=1/1`，并可能看到 `settle` 小于 500 ms。
- 普通开放步骤确认目标应为 `frames=.../4`，`drain` 约 700 ms。
- 物体邻域严格步骤仍应为 `adaptive=0/0`、`frames=.../6`、`drain` 约 1000 ms。
- 若短距矫正堵转，应看到 `stall_retry=1`，随后进入视觉等待和重试或重规划，不应立即出现任务 `FAULT STALLED`。
- 若主体 200 mm 网格运动本身堵转，仍应正常硬停。

局部三步正常后再按 `A` 完整运行。
