# 7100897 M3通过与正式逐格M4

## 1. M3左上区域采集结论

版本：MCU `7100896`，视觉 `oa_id=7100422`。

本轮在地图左上代表区域约 `(2.7,2.8)` 执行唯一一次 `QUICK12`，结果为 `COMPLETE`、`valid=12`、`invalid=0`，没有 `STALL`、`PAUSED` 或人工推动。12段均为稳定视觉6帧、bad=0，串口 `txdrop=0`。

编码器沿程均值：

- 前进：209.1/201.1/202.4mm，均值204.2mm。
- 后退：200.6/203.9/198.7mm，均值201.1mm。
- 右移：202.8/201.2/199.3mm，均值201.1mm。
- 左移：201.2/195.3/208.7mm，均值201.7mm。

与中心区基线190.5/197.1/196.7/200.1mm相比，四方向均值差分别约为+13.7/+4.0/+4.4/+1.6mm，全部小于预设20mm区域差门槛。编码器二维闭环残差约12.4mm；视觉绝对坐标由约 `(2.7,2.8)` 回到 `(2.8,2.9)`，约28mm，属于当前0.1格量化范围。

结论：M3通过。当前没有证据支持建立复杂的“方向 x 区域”查找表，因此不采集右下区域、不实装区域LUT。继续采用全局方向独立制动值：前50mm、右30mm、后47mm、左20mm。视觉角度仍不作为运动中的实时航向主参考；稳定后的视觉绝对位置用于每格终点确认，IMU负责运动期间锁航向。

## 2. 正式模式审计发现

正式Action执行原先存在两个风险：

1. 每一格都可能使用当时的视觉角度重新计算车体方向，视觉角度抖动会直接改变轮组运动方向。
2. 从当前视觉坐标直接对目标格中心做 `atan2`，会把本应四方向的一格动作变成斜向追点，并落入尚未标定的斜向制动逻辑。

这两点与已经通过实车验证的“四方向200mm主体运动 + IMU锁航向 + 停车后视觉确认”不一致，必须在正式M4前修正。

## 3. 7100897修改

修改文件：

- `project/code/action_follower.c`
- `project/code/pc_console.c`
- `project/user/src/main.c`

关键逻辑：

- `CONTROL_DEBUG_ENABLE=0U`，恢复正式菜单模式。
- 按 `E` 装载任务时，只采集一次稳定视觉角度，并量化到最近的0/90/180/270度地图朝向。
- 原始角度距离最近四方向超过30度时拒绝ARM，车保持锁止。
- 同时锁定当前IMU航向，任务期间不再用实时视觉角度改变运动方向。
- 每一格方向严格由算法的相邻格 `from -> to` 决定，只允许地图四方向。
- 视觉位置只投影到该计划轴上，用于修正本格剩余沿程距离；不再产生斜向轮组命令。
- 每格仍执行编码器主体运动、IMU锁航向、停车500ms、旧视觉帧排空1000ms、稳定6帧及100mm终点门控。
- 按 `E` 后的状态立即显示视觉原始角度 `ref` 与量化地图朝向 `used`，允许在第一次按 `N` 前检查朝向。

未修改：三个电机/编码器物理映射、方向符号、PID、CPR4096、里程比例0.915、轮径58mm、速度120、起步补偿、堵转保护、四方向制动提前量和视觉协议。

## 5. M4通过顺序

M4必须分步推进，禁止首轮直接按 `A`：

1. 使用无炸弹地图（优先map2）请求全图并解算，确认计划有效。
2. 只执行计划中的第一个 `FREE` 单格，验证正式中间层到控制层方向、距离和停止确认。
3. 单格通过后，再从新上电执行若干连续 `N`，观察转向后的相邻单格。
4. 连续分步通过后，才允许从新上电执行 `A` 完整跑图。

第一次正式单格回归的完整操作：

```text
重新上电并静止3秒
-> 确认id=7100897、stage=FORMAL_GRID_M4、VISION CONNECTED且坐标合理
-> 1
-> 等待FULL_MAP received和MAP_END
-> 2
-> D
-> 确认PLAN_SUMMARY valid=1/current=1，并确认第一条GRID_EXEC为FREE
-> B
-> 3
-> E
-> 确认ARM result=OK，并检查ref/used没有异常跳变
-> N
-> 等待该格进入STEP_WAIT或DONE
-> S
```

若第一条网格动作是PUSH，不执行本轮 `N`，按 `X` 并回传日志；若ARM返回BAD_STATE，保持车不动等待3秒后重试 `E` 一次。测试期间不要按 `A`、不要手推。回传从上电到 `S` 的完整日志，并说明肉眼实际运动方向和距离。
