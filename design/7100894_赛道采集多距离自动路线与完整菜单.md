## 3. 自动路线

所有自动路线均复用既有 point_test M4：编码器主体运动、IMU锁定同一会话航向、停车保持500ms、排空1000ms延迟视觉、等待6个稳定视觉帧，再记录结果。每个自动会话只在开始时确定一次IMU航向目标。

- `QUICK12`：12段，每段连续1格；四方向各3次，最终闭合。
- `GRID2_12`：12段，每段连续2格（400mm）；四方向各3次，最终闭合。
- `GRID3_12`：12段，每段连续3格（600mm）；四方向各3次，最终闭合。
- `LENGTH36`：依次完整执行1格、2格、3格的QUICK12，共36段；每个“方向+长度”组合各3次，最终闭合。
- `STANDARD60`：保留旧60段单格路线；所谓连续两格模式仍是两次单格并在中间停车。
- `FULL180`：STANDARD60分别以速度100、120、150执行，共180段。

路线静态检查：GRID1/GRID2/GRID3分别为12段，F/B/R/L各3次，闭合位移均为0；LENGTH36共36段，每个方向在1/2/3格下各3次，闭合位移为0。

## 5. 下一次实车流程

先跑两格，不要先跑三格或LENGTH36。车放在地图中部，前后左右至少留2格净空：

```text
重新上电静止3秒 -> Z -> 2 -> 2 -> R -> 等待COMPLETE -> S
```

把完整串口输出和肉眼测得的四方向实际距离发回。分析一格与两格误差：若绝对误差近似不变，优先调整方向独立制动提前量；若误差近似随距离成倍增长，优先处理方向比例/运动学；若横偏随距离增长，检查航向与轮间平衡。

两格通过后，三格流程为：

```text
重新上电静止3秒 -> Z -> 2 -> 3 -> R -> 等待COMPLETE -> S
```

`LENGTH36`只在四周至少留3格、两格和三格均无安全问题时运行：

```text
重新上电静止3秒 -> Z -> 2 -> 4 -> R -> 等待COMPLETE -> S
```

## 6. GRID2_12首次实车结果

GRID2_12以速度120完成全部12段：`valid=12`、`invalid=0`、`txdrop=0`、每段稳定视觉6帧且`bad=0`，最终正常进入COMPLETE。

400mm目标的三次均值：

| 方向 | 编码器纵向 | 视觉纵向 | 编码器平均横向 |
|---|---:|---:|---:|
| 前 | 411.6mm | 393.6mm | -5.0mm |
| 后 | 399.4mm | 371.9mm | -1.3mm |
| 右 | 385.0mm | 366.7mm | -8.5mm |
| 左 | 374.6mm | 353.0mm | 3.2mm |

整条理论闭合路线的编码器净位移约为前`+71.9mm`、右`+20.2mm`，模长74.7mm；视觉绝对起终点约从`(6.9,5.2)`到`(7.2,5.4)`，即约前`+60mm`、右`+40mm`。编码器和视觉再次证明偏移是真实方向距离不对称，不是通信或静止视觉噪声。

与一格均值联合拟合 `实际距离=k*目标距离+b` 得到：前`k=1.054,b=-10mm`；后`k=1.015,b=-6mm`；右`k=1.035,b=-29mm`；左`k=1.039,b=-41mm`。左右两格误差没有按一格误差成倍增长，说明固定起停/制动偏差占主要部分，不支持直接修改全局CPR或0.915比例。

暂不修改制动提前量和PID，保持相同参数执行GRID3_12验证上述线性趋势。预测三格编码器均值约为：前622mm、后602mm、右592mm、左582mm。若实测接近预测，再设计按方向、必要时按距离/速度变化的制动提前量；正式比赛仍以一格精度为最高权重。

## 7. GRID3_12部分结果与第10段失速

GRID3_12前9段均正常完成并有效。600mm目标的已取得编码器均值为：前607.6mm（3次）、后604.0mm（2次）、右588.8mm（2次）、左574.3mm（2次）。与两格结果相比，方向误差基本保持固定量，没有随距离成倍增长，进一步确认起停/制动固定偏差是主因。

第10段左移启动后只前进约12.9mm，随后约30秒保持`RUNNING`、`speed=120/120`、`remain=587mm`。三轮累计脉冲仅`(245,-198,-262)`，平均编码器速度均被取整为0，但控制器持续输出平均PWM`(3319,1271,1407)`，峰值`(3357,1550,1677)`。最终按三格30秒超时进入`POINT_FAULT/TIMEOUT`并安全锁车。

这不是视觉等待，也不是软件主动停车：运动状态下`device_init_flag=0`，速度环仍每5ms调用`p_set()`写PWM。高PWM而三轮编码器均近零说明整车发生共同失速，优先检查电机公共电源/电池压降、驱动过热保护、机械阻挡或线缆卡住。不要直接按C重试。

继续实车前应增加约1秒的“有运动命令且高PWM、但进度几乎不增长”失速保护，避免再次持续堵转30秒。现有三格样本已经足够验证距离趋势，无需原样重跑完整GRID3_12。

## 8. GRID3_12第二次结果及左移启动卡滞定性

第二次运行中，自然完成的600mm编码器均值为前605.4mm、后617.0mm、右587.9mm、左576.4mm。与上一轮合并约为前606.5mm、后611.8mm、右588.2mm、左575.4mm；三格距离趋势已经足够，禁止继续重复GRID3_12。

第8段左移在19mm处停滞约18秒，人工轻推后恢复并完成到574.5mm。该段最终距离与自然左移一致，可谨慎用于停止距离趋势；耗时、平均速度、平均PWM被人工推车污染，不得用于控制参数拟合。第12段右移编码器580.1mm和IMU数据可用，但视觉起点角度异常为0度并触发`GRID_MISMATCH`，该段视觉数据作废。

代码确认正常模式没有命中2500 PWM调试限幅，最终PWM上限为10000，实测峰值也远未饱和。左移速度120时，后轮目标约+120、两前轮约-60；位置补偿上限为基础目标45%，前轮补偿后最多约-87。当前速度环Kp=18/18/20且没有静摩擦前馈，停转时得到约1500至1800的前轮PWM，可能低于偶发起步死区。两轮测试均只在左移出现长停，轻推后立即恢复，现阶段把根因定为左移低轮速通道的启动静摩擦/死区问题，而不是最终PWM硬限幅。

下一版应先加入约1秒失速保护，再加入短时起步前馈或按轮/方向的最小有效PWM；不要先改PID、CPR或里程比例。修改后只测试一次左移一格，不再跑GRID3_12。
