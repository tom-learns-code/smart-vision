# 7100963 三按键离线屏幕菜单

## 任务定位

本轮暂停二号摄像头识别精度支线，回归完整三图比赛主线，先验证没有无线串口时可独立完成配置、准备、启动和急停。当前使用 IPS200 竖屏和三个低电平按键：`C12/C13/C14`。

## 硬件结论

- `C12/C13/C14` 均未被当前电机、编码器、IPS200、全局摄像头或二号摄像头占用。
- 三键配置为 GPIO 输入、内部上拉、低电平按下。
- 屏幕 SPI 使用 `B0/B1/B2/B3/C18/C19`，与三键无冲突。
- 正式比赛构建设置为 `APP_UI_SCREEN`；不初始化 `wireless_uart_init()`，不初始化或轮询 `pc_console` 菜单。
- MCU 底层 `debug_init()` 仍会配置 UART8 的 `D16/D17`，但没有无线模块时不会影响屏幕和三键，比赛交互完全不依赖它。

## 三键定义

- `C12` 短按：上一个菜单项；长按：取消任务、解除准备并停车。
- `C13` 短按：下一个菜单项；长按：紧急停车，进入 `FAULT`。
- `C14` 短按：修改当前选项；长按：第一次准备，屏幕进入 `ARMED`，第二次长按正式启动。
- 消抖 30 ms；短按不超过 450 ms；长按不少于 900 ms。
- 上电时若某键被按住，必须先松开，该次按压不会触发命令，防止上电误启动。

## 菜单字段顺序

`PRESET -> R1 RUN -> R1 STRATEGY -> R1 SPEED -> R1 ALGORITHM -> R2四项 -> R3四项 -> ARM/START`

可选值：

- `RUN`：`RUN/SKIP`。
- `STRATEGY`：`SAFE/NORMAL/SPRINT`。
- `SPEED`：`100/120/150`。
- `ALGORITHM`：`BOX/IMG/BOMB`，分别对应纯箱子、无炸弹图片识别、炸弹图片识别。
- 修改任意逐轮字段后预设名显示为 `CUSTOM`。

## 屏幕信息

屏幕显示固件 ID、比赛状态、预设、三轮配置、当前选项和值、当前轮次、已完成轮次、门控、故障和最近一次按键结果。界面最低行位于 `y=272`，IPS200 竖屏有效区域为 `240x320`，无越界。

## 第一次实机测试

1. 不接无线串口，接好 IPS200 和三个按键，下载 MCU7100963 后重新上电。
2. 屏幕应显示 `OFFLINE 3KEY ID7100963`、`STATE:IDLE` 和默认 `PRESET:SAFE_ALL`。
3. 车轮先悬空或保持总电源安全，只短按 `C12/C13`，确认 `SELECT` 能双向循环且一次只移动一项。
4. 选中 `R1 SPEED`，短按 `C14` 三次，确认依次显示 `150 -> 100 -> 120`；选中 `R1 RUN`，确认 `RUN/SKIP` 切换。
5. 长按 `C14` 一次，确认状态变为 `ARMED`，车不应运动；长按 `C12`，确认回到 `IDLE`。
6. 再长按 `C14` 进入 `ARMED`，第二次长按 `C14` 才会正式发车。此项必须放到赛道上、摄像头和 IMU 已就绪后测试。
7. 运行中长按 `C13`，应立即停车并显示 `STATE:FAULT`、`FAULT:OPERATOR_STOP`。

下一步先完成第 1 至 5 项纯菜单验收；通过后再进行第 6 至 7 项启动与急停验收。
