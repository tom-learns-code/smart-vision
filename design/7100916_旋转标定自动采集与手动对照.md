## 任务归属

## 主动旋转控制

主动旋转支持`45/90/135/180°`，顺时针和逆时针均可。每一步开始时保存同一个连续IMU基准，并给本步设置绝对目标航向；自动往返不会把上一转的小误差重新当成下一转基准。

- 默认旋转速度80 counts/5ms，可在菜单切换60/80/100。
- 距目标20°以内自动降到60，减小惯性过冲。
- 到达目标后不再保持“实际停下时的偏角”，而是切换到原定目标航向闭环。
- 至少保持500 ms；当目标误差不超过1.5°且陀螺Z轴不超过3°/s，连续稳定200 ms即可完成；最长保持2 s后结束，防止死等。
- 每步电机锁定后先排空1 s视觉延迟，再采6个稳定新位置帧；稳定簇至少维持200 ms，位置簇容差0.1格，视觉角度簇容差15°，最长等待4 s。
- 视觉超时只把该条记录标成无效并继续自动序列，不会让整套AUTO16永久锁住；真实旋转超时、IMU未就绪及点测故障仍进入暂停/硬保护。

AUTO16在每个角度上执行四步：`CW转出 -> CCW回原航向 -> CCW转出 -> CW回原航向`。角度顺序是`45 -> 90 -> 135 -> 180°`，一轮共16条；重复数可选1/3/5轮，即16/48/80条。

## 手转对照

手转模式进入后PWM为0、航向保持关闭、驱动输出锁定。用户按菜单选定的角度和方向手动转动车身，停稳后按`P`；固件记录三个轮子的相对编码器计数与IMU变化，然后执行同样的1 s视觉排空和6帧稳定采集。手转数据用于把主动控制误差和机械/几何误差分开，不用于直接修改控制参数。

旋转子菜单：

```text

D        切换CW/CCW
S        切换速度60/80/100
N        切换AUTO16重复数1/3/5
R        主动单次旋转
Q        主动转出并精确回到启动航向
A        自动执行AUTO16

P        手转后提交；非手转状态下打印当前/最后结果
B        返回
X        紧急停止并中止采集
H        重印当前菜单
```

## 串口记录

每条完成记录输出：

- `ROT_REC`：session、模式、序列、步号、有效性和故障。
- `ROT_CFG`：目标角、方向、速度、连续目标航向、耗时和保持稳定时间。
- `ROT_IMU`：起始/触发停车/最终航向、实际变化、最终误差和过冲。
- `ROT_ENC`：后轮/左前/右前计数、编码器估算角度、反算有效轮心半径。
- `ROT_VIS`：延迟视觉的起终位置/角度、视觉角变化、角度簇跨度和帧龄。
- `ROT_DRIVE`：三轮平均速度、平均PWM和PWM峰值。
- 运行遥测新增`POINT_ROT`：目标、实时误差、触发停车航向、过冲、降速段、稳定保持时间和陀螺Z轴。

## 实车采集顺序

先完成短流程，确认方向和停止逻辑后再跑AUTO16：

```text
下载 project/mdk/Objects/rt1064.axf
-> 完整重新上电并确认 id=7100916 stage=ROTATION_CAL_AUTO16
-> 等待 VISION CONNECTED，车静止到视觉坐标稳定
-> 7 -> 2 -> S（循环到speed=80）-> R
-> 等待ROT_REC，确认实际为90度CW且无持续疯转
-> D -> R
-> 等待ROT_REC，确认实际为90度CCW
-> Q
-> 确认转出后能回到原航向
```

短流程通过后自动采集：

```text
完整重新上电
-> 等待 VISION CONNECTED且车静止
-> 7 -> S（确认speed=80；不对则继续按S）
-> N（确认repeat=1；不对则继续按N）
-> A
-> 不再按键，等待 state=COMPLETE 和16条ROT_REC
```

手转对照每次都重新上电，避免累计误差：

```text
7 -> 选择角度1/2/3/4 -> D确认方向 -> M
-> 人工按约定真实方向转到目标角并保持不动
-> P
-> 继续保持不动，等待ROT_REC
```

采集时保证车轮悬空或车辆周围有足够空地；任一方向与菜单相反、持续加速、机械碰撞风险或无法停稳时立即按`X`并断电。回传时保留从`#MCU_BOOT`到最后一条`ROT_REC`的完整文本，并注明肉眼实际角度/方向及最终偏差。
