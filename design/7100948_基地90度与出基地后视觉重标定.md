# 7100948 基地90度与出基地后视觉重标定

## 目标

- 基地内默认车身处于地图航向90度。
- 基地位于屏幕第0列边缘，基地内不采用全局视觉角度，避免暗角、裁切和边界伪色块影响发车。
- 底层IMU是局部角度系，因此发车时锁定“静止后的当前IMU角度”，而不是把地图90度直接写成IMU目标。
- 出基地停车后重新请求FULL_MAP，再由现有的6帧位置与6帧视觉航向流程重建地图/车身/IMU角度关系。

## MCU改动

- 识别数：`7100948 / BASE90_POSTVIS_REBASE`。
- `MATCH_STATE_EXIT_PREP`先等待IMU满足：角速度不超过5 deg/s、200 ms内航向漂移不超过2度。
- 稳定后捕获当前IMU航向并作为整个出基地平移的锁航向目标。
- 等待最长1.5 s；超时使用最新IMU角度继续发车，不形成新的永久门控。
- 发车仍使用原有前/左/右相对车身方向和350 mm默认距离。
- 出基地结束后保持原流程：请求新版FULL_MAP -> 解算 -> 6帧位置复核/格心对齐 -> 6帧视觉航向中值 -> 建立任务航向参考。

## 验证重点

- 发车前允许看到约200 ms的`gate=HEADING_STABLE`，随后必须自动进入`EXIT_RUNNING`。
- 发车最初几帧的`yaw err/corr`不应立刻打满，轮速目标应符合所选平移方向。
- 出基地后必须出现`WAIT_NEW_MAP`和新版地图，随后进入任务的`START_POSE_WAIT/START_HEADING_WAIT`。
- 基地内视觉theta只用于链路可见性，不参与发车航向锁定。
