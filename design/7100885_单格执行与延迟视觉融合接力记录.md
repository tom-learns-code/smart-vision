## 1. 当前首要目标

尽快形成能上整图验证的最小闭环：

1. 视觉层持续发送车辆位置和角度。
2. MCU 根据当前地图完成求解。
3. 原来一个 `FREE_MOVE` action 中的多格路径拆成逐格执行。
4. `N` 每次只走一个相邻格。
5. `A` 也按一格一格执行，每格结束后停车并等待延迟视觉稳定，再开始下一格。
6. 暂不执行 `PUSH_BOX`；运行到首个推箱动作时必须锁车并报告 `PUSH_LOCKED`，不得误动作。

## 4. 视觉协议变更

位置帧 payload 的第 0 字节现在定义为：

- bit7：`car_valid`，1 表示本次图像确实检测到车，0 表示未检测到。
- bit6..0：`frame_id`，范围 0..127。

视觉层即使暂时丢车，仍可发送保留坐标用于调试，但 `car_valid=0`。MCU 此时保持链路在线，却不得把保留坐标当作有效定位，也不得启动下一格。

FULL_MAP 不再覆盖 MCU 中的位置状态。位置和有效性只由 POS_UPDATE 更新，防止全图帧中的旧坐标污染实时位置。

视觉地图四条边界已经在 `force_map_boundary_walls()` 中强制写为墙。

## 5. 单格执行数据流

完整链路：

`FULL_MAP/POS_UPDATE -> vision_link -> vision_world -> planner_service -> solver actions -> mission_manager 微步 -> action_follower -> point_test M4 -> motion_control`

### 5.1 action 拆分

- `FREE_MOVE` 的 `wp_count` 个 waypoint 被拆成 `wp_count - 1` 个相邻格微步。
- 每个微步必须满足曼哈顿距离恰好为 1。
- `N` 成功一次只增加一个 `substep_cursor` 和一个全局 `step_cursor`。
- `A` 只是自动重复相同的单格流程，不允许跳过视觉确认。

### 5.2 每格实际执行

1. 电机保持锁止，等待有效且稳定的视觉位置。
2. 检查车辆距离计划起点格中心不超过 120 mm。
3. 使用最新视觉坐标计算到目标格中心的剩余距离和方向，而不是盲走固定 200 mm。
4. 将地图方向减去视觉航向角，得到车体坐标系运动方向。
5. 调用已实测的 point-test M4：编码器控制位移，IMU 保持航向。
6. 剩余约 50 mm 时制动，停车保持 500 ms。
7. 丢弃约 1000 ms 的延迟视觉数据。
8. 等待 6 帧位置聚类稳定且持续至少 200 ms。
9. 视觉确认通过后才把该格记为完成。

默认比赛单格速度是 `120 counts/5ms`，可从运行菜单切换为 100/120/150。没有新增 PWM 或速度硬上限，现有电机、编码器、PID、CPR4096、58 mm 轮径、0.915 里程比例和 50 mm 制动提前量均未改动。

## 6. 安全条件

以下情况必须停止，不得自动开始下一格：

- 视觉离线、位置帧过期或 `car_valid=0`。
- 当前视觉位置距离计划源格中心超过 120 mm。
- waypoint 不是相邻格。
- point-test 超时、过行程或视觉确认超时。
- 最终视觉位置与目标格中心偏差过大。
- 地图版本变化导致原计划失效。
- 运行遇到 `PUSH_BOX`。

暂停当前格会中止本格并要求重新规划，当前版本不支持在半格位置直接续跑。

## 7. 菜单语义

主菜单：

- `1`：请求一帧 FULL_MAP 并打印。
- `2`：进入求解菜单。
- `3`：进入运行菜单。
- `4`：打印视觉链路状态。
- `5`：打印 MCU 缓存地图。
- `X`：紧急停车。

求解菜单：

- `D`：求解并打印详细 action，同时打印拆开的 `Sxxx FREE` 单格清单。
- `S`：只打印求解摘要。
- `B`：返回主菜单。

运行菜单：

- `E`：锁定当前有效计划并进入待执行状态。
- `N`：只执行下一格 FREE 微步。
- `A`：自动逐格执行后续 FREE 微步，每格都经过完整 M4 停车和延迟视觉确认。
- `P`：中止当前格，之后必须重新规划。
- `R`：仅在尚未移动时重置执行游标。
- `K`：解除计划锁定并停车。
- `S`：打印当前 action、子步、全局步和 follower 状态。
- `T`：切换运行遥测。
- `1/2/3`：速度选择 100/120/150。

到达推箱动作时的正常结果是 `PUSH_LOCKED`。这不是通信故障，而是当前阶段有意设置的安全停止点。
