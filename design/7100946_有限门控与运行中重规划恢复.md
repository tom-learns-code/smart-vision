# 7100946 有限门控与运行中重规划恢复

## 1. 任务归属

本轮属于完整比赛主线的阻塞修复。7100945 实车在普通移动 `(8,6)->(9,6)` 完成编码器位移后进入 `WAIT_VIS_STABLE`，上位机位置帧持续停在错误坐标，执行器永久锁止。目标不是取消所有保护，而是保证任何视觉门控都有明确出口，并让可恢复异常继续完成当前地图。

修改前备份：`project/_codex_backups/pre_7100946_RUNTIME_RECOVERY_20260721_153500`。

## 2. 本轮实现

### 2.1 action_follower 有限等待

- `WAIT_VIS_ORIGIN` 总等待上限为 2 秒。
- 普通视觉复核等待上限为 2.5 秒。
- 开局、环境切换、物体八邻域等强重定位等待上限为 3 秒。
- 已接触箱子/炸弹的 loaded-push 复核等待上限为 4 秒。
- 普通非交互路段超时后使用编码器里程计和 IMU 锁航向继续；连续逻辑接力上限为 32 格。
- 关键区、强重定位和 loaded-push 不盲目放行，超时转入 `REPLAN_REQUIRED`。
- 稳定视觉位置若同时离当前逻辑起点和终点超过 300 mm，判作上位机跳变，不用该帧进行跨图强修正。
- 普通路段起点若视觉滞后一格、误差超过 120 mm，直接使用规划逻辑格位继续；箱子、炸弹、目标点和环境切换不适用此降级。
- 原 `target_distance` 非法时的无出口 `return` 已改为有限的疑似帧等待或显式重规划。

### 2.2 普通路段取消逐格视觉停顿

- 普通、非交互、非强重定位的一格动作启用 `fast_finish`：停车稳定后直接进入下一动作，不再逐格执行 1 秒视觉排空与稳定帧等待。
- 开局格心、墙环境切换、箱子/炸弹/目标点八邻域、推动前后、观察点仍保留完整有限强矫正。
- NORMAL/FAST 合并直线段仍在整段终点保留一次重定位，不是完全关闭视觉。
- 运动过程中原有 IMU 航向锁定、编码器里程和有界视觉横向纠偏继续工作。

### 2.3 match 运行中恢复

- `MISSION_RUNNING` 收到 `PAUSED_REPLAN + REPLAN_REQUIRED` 时不再直接结束当前轮。
- MCU 立即锁止电机、主动请求一帧新的 FULL_MAP，等待地图版本推进以及至少 4 个新位置帧、连续 200 ms 稳定。
- 使用最新地图和当前位置重新解算、重新武装并恢复本轮任务。
- 每轮最多运行中重规划 3 次；串口 `MATCH_CFG` 新增 `runtime_replan=x/3`。
- 真正的 `MISSION_FAULT`、新地图长期不到、重规划连续 3 次失败仍保留硬停/失败出口，避免结构性故障无限循环。
