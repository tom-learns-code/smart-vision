# 7100920 动态物体邻域与开局格心重锚

## 目标

本轮优先解决两个会直接影响完赛的问题：

1. 箱子或炸弹被推动后，其当前位置必须继续影响后续执行档位；车辆进入物体八邻域时只能一格一格运行，并在每格末端严格确认格心。
2. 任务刚进入`3 -> E`后，车辆必须先用稳定视觉验证当前格，并在需要时物理移动到格心；完成重锚前不允许`N/A`启动主路径。

延迟视觉卡尔曼/固定滞后融合已记录为后续增强，本轮不替换现有编码器、IMU和视觉门控。

## 动态物体上下文

中间层每次准备一个网格步时，都使用`mission_expected_map`重新计算起点和终点的3x3邻域：

- `box_near`：邻域内存在当前箱子；
- `bomb_near`：邻域内存在当前炸弹；
- `object_near = box_near || bomb_near`；
- `goal_near`：邻域内存在目标点。

PUSH执行前，算法动作中的对象起点/终点用于生成事务性期望地图；PUSH成功后才提交对象的新位置。炸弹推入墙体并引爆时，炸弹会从期望地图删除并清除对应3x3墙体。因此下一步上下文读取的总是移动后的对象位置，不依赖初始FULL_MAP中的旧坐标。

物体、目标点邻域或PUSH步骤统一设置：

- `segment_cells=1`，禁止FAST_SAFE合并；
- `strong_reanchor=1`，禁止墙边同格坐标放宽；
- `strict_position=1`；
- 视觉排空1000ms，稳定6帧且跨度至少200ms；
- 严格通过阈值为单轴20mm、合成距离30mm；
- 最多执行3次格心校正，仍未达标则请求重规划；
- 不允许编码器/无视觉完成兜底。

普通开放区、单边墙和走廊仍保留原有容错。与物体交互且贴墙时，实时横向修正仍使用较小的PUSH墙边增益，避免视觉贴墙钳位把车辆推向墙体；最终格心确认仍采用严格模式。

## 开局格心重锚

`mission_manager_arm_plan()`完成地图、计划、当前位置和航向基准校验后，不再直接进入`STEP_WAIT`，而是进入：

1. `START_POSE_WAIT`：电机锁定，等待6个稳定位置帧且稳定时间不少于200ms；
2. 若稳定位置已在计划起始格中心20mm以内，记录`result=1`并放行；
3. 若仍在同一格、距格心不超过180mm，则进入`START_POSE_ALIGN`，使用IMU锁航向和严格位置重锚物理移动；
4. 移动完成后重新进入`START_POSE_WAIT`采新帧复核，达标后记录`result=2`；
5. 稳定视觉落在其他格、超过180mm或5秒内无法得到稳定位置时锁车，不启动主路径。

炸弹P1任务的第二摄像头会话可与开局重锚并行初始化；格心复核完成后，如果FP2尚未就绪则进入`FP_SESSION_WAIT`，两项都完成后才进入`STEP_WAIT`。

## 串口观察字段

新MCU识别号为`7100920 / OBJECT_NEAR_START_REANCHOR`。

- `MISSION_START`：开局目标格、稳定帧、耗时、当前位置和格心误差；
- `MISSION_EXEC near[...] strict=`：当前动态箱子/炸弹/物体/目标点邻域和严格模式；
- `RUN_VIS strict=1 pass=20/30mm`：严格位置确认已生效；
- `RUN_GUARD start[...]`：开局重锚过程；
- PUSH仍通过`PUSH kind=... obj=(x,y)->(x,y)`展示中间层对象迁移。

## 构建与使用

`CONTROL_DEBUG_ENABLE=0/1/2/3`均使用ARMCLANG 6.16构建通过，均为`0 Error(s), 0 Warning(s)`。标准`project/mdk/Objects/rt1064.axf`为模式0，SHA256：

`0DB2D2AAE7A7B70A3D1447EAE47AF9785C38971900A38A36372DE225ACBCE905`

第一次实车验证建议使用STANDARD，完整重新上电后：

`1 -> 等待FULL_MAP/MAP_END -> 2 -> D -> 等待PLAN_SUMMARY valid=1/current=1与PLAN_CHECK ok=1 -> B -> 3 -> E`

按`E`后先观察`START_POSE_WAIT`。如果车辆本来就在格心，应出现`MISSION_START result=1`并进入`STEP_WAIT`；如果存在偏移，应看到一次低速重锚、复核后`result=2`。只有进入`STEP_WAIT`后再执行：

`N -> 等待STEP_WAIT -> N -> 等待STEP_WAIT -> N -> 等待STEP_WAIT -> A`

经过箱子或炸弹八邻域时，应看到`object=1 strict=1`、`gear=BOX_NEAR_PRECISE/PUSH_PRECISE`和`RUN_VIS pass=20/30mm`。若严格校正连续3次仍无法达到20/30mm，进入重规划是预期保护，不应继续盲推物体。
