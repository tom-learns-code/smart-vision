# FP2 极简三帧均值 Worker

## 现场证据

- MCU7100962 已完成同请求重试，但图片和数字仍超时。
- 挂载现场：`fp2_job.bin` 为 session2/request2 的数字请求；`fp2_trace.bin=0x24`；`fp2_last.bin` 不存在。
- `0x24` 表示数字 worker 已完成任务读取、传感器初始化和 UART 初始化，进入模型加载/推理段后退出。故障不在请求链、会话或结果匹配，而在新增三帧正式 worker 的运行规模。

## 修改

- 图片 worker 更新为 `7200134`，数字 worker 更新为 `7200135`。
- 继续保留每个模型三帧识别，并对十个类别概率逐项累加后求均值。
- 每帧只取当前 ROI 的第一个分类输出，不再维护候选峰值对象；立即累加后释放图像。
- 数字标签固定为模型类别 0到9，删除运行时读取 `digit_labels.txt`；其文件内容已确认就是顺序 0到9。
- 删除 worker 中比赛期间不可见的长字符串打印，保留 `fp2_trace.bin` 阶段诊断。
- 图片 worker 从 6732B 压缩至 6003B；数字 worker 从 6564B 压缩至 5539B。数字版已小于此前成功生成结果的单帧版，图片版也略小于旧单帧版6072B。
