# 7100957 主动结束异常本轮并复核返航

## 实测结论

7100956整轮运动总体稳定。日志中推箱/炸弹和推后重锚均继续推进，运行时重规划达到`3/6`后仍能重新取得非空地图和稳定位置，没有重现永久`WAIT_POSE`。最后未完成的是实体箱子被上位机抖动带离逻辑格位，地图剩余`1箱/1目标`，MCU继续按原规划格尝试推动。这个现象属于外部世界与离散规划模型持续不一致，不适合继续修改运动层。

## 修改内容

`match_manager_withdraw_round()`提供受控的本轮撤回入口，只接受以下状态：

- `SOLVING`
- `MISSION_ARMING`
- `MISSION_RETRY_WAIT`
- `MISSION_RUNNING`

接受后按顺序执行：

1. 停止mission、follower、point-test和底层电机命令。
2. 清理当前mission自动运行和重试上下文。
3. 将本轮标记为未完成，原因记为`REPLAN_REQUIRED`。
4. 请求多帧FULL_MAP并进入`FINISH_MULTI_MAP`。
5. 地图非空时由AUTO策略进入已有BFS返航；地图清空时保持原有直返。

UART入口位于完整比赛诊断页：`D -> R`。放在子菜单中等同两次按键确认，避免主菜单误触。成功接受会输出：

`ROUND WITHDRAW accepted: motors stopped; finish scan and AUTO return started.`
