# 7100966 独立运行与界面开关

## 目标

把经常手动切换的运行模式、正式比赛界面和六模式参数恢复到`main.c`开头的“用户常用运行配置”，使用直接数值修改。运行模式与界面模式彼此独立，且不再与`app_config.h`中的二级别名冲突。

## 当前用户配置

```c
#define CONTROL_DEBUG_ENABLE   (0U)

#define RACE_UI_UART           (0U)
#define RACE_UI_SCREEN         (1U)
#define RACE_UI_MODE           (RACE_UI_SCREEN)

#define CONTROL_VERIFY_MODE    (3U)
#define RACE_FREE_MOVE_SPEED   (120.0f)
#define CONTROL_VERIFY_MOTOR   (0U)
#define CONTROL_VERIFY_PWM     (2000U)
#define CONTROL_VERIFY_MODE5_SPEED (300.0f)
#define CONTROL_VERIFY_MODE5_LIMIT_ENABLE (0U)
```

## 使用规则

- `CONTROL_DEBUG_ENABLE=0`：正式比赛。此时`RACE_UI_MODE`才生效。
- `RACE_UI_MODE=RACE_UI_UART`：初始化UART8无线菜单，不初始化IPS200比赛菜单。
- `RACE_UI_MODE=RACE_UI_SCREEN`：初始化IPS200和C12/C13/C14，不初始化或轮询无线串口菜单。
- `CONTROL_DEBUG_ENABLE=1`：六模式硬件验证，固定使用屏幕，与`RACE_UI_MODE`无关。
- `CONTROL_DEBUG_ENABLE=2/3`：点到点或赛道采集，固定使用UART8菜单，与`RACE_UI_MODE`无关。
- `RACE_FREE_MOVE_SPEED`只是动作跟随器初始化速度；进入每轮后由对应预设中的100/120/150速度接管。

`app_config.h`中原有`APP_CONTROL_MODE`、`APP_UI_MODE`和`APP_VERIFY_*`配置已删除，避免重复入口。按键时序、比赛策略、物理参数和SKIP逻辑仍保留在集中配置中。
