## 1. 当前目标

新增 `CONTROL_DEBUG_ENABLE == 3U`，用于集中采集赛道上的编码器、IMU、全局视觉和电机负载数据，为后续离线拟合方向/位置相关修正表提供原始记录。

模式 3 不使用 IPS200，只使用无线调试串口 UART8：115200，TX=D16，RX=D17。视觉链路仍是 MCU 与 OpenART 之间的原串口，视觉代码本次没有修改。

运动执行仍复用已实车验证的 `point_test` M4，不复制电机控制：

1. 连续 6 个不同 frame_id、持续至少 200ms 的稳定视觉才能取起点。
2. 主体运动由编码器 200mm + IMU 固定航向完成。
3. 到点后停车并保持 500ms。
4. 排掉 1000ms 延迟视觉帧。
5. 再等待 6 个稳定视觉帧并比较编码器终点。
6. 视觉纵向或横向误差超过 100mm、视觉超时或点对点故障时暂停，不自动跳步。

整次自动路线固定使用启动时的 IMU 航向目标，不会每走一格重新接受已经偏掉的车身方向。

## 4. 自动路线

自动路线的每一个动作都是单独的一格，完成停车和视觉确认后额外等待 500ms 再开始下一格。

- `QUICK12`：12 格。F/B、R/L、顺时针正方形、逆时针正方形；最大离起点约 1 格，最终回到起点。
- `STANDARD60`：60 格。四方向各 15 格，包含单格往返、连续两格往返、顺/逆时针正方形；最大离起点约 2 格，最终回到起点。
- `FULL180`：把 STANDARD60 分别以速度 100、120、150 跑一遍，共 180 格，最终回到起点。

路线静态检查结果：STANDARD60 的 F/B/R/L 均为 15 次，最终位移 `(0,0)`；FULL180 三个速度段均闭合。

## 5. 菜单

主菜单：

- `1` 手动采集
- `2` 自动采集
- `3` 静止视觉/IMU 稳定性测试
- `4` 连续请求 5 帧 FULL_MAP 并比较格子差异
- `5` 速度、格数、重复次数、载荷、电压标签
- `6` 当前会话摘要和最后一条完整记录
- `Z` 验证稳定视觉原点，电机不启动
- `T` 开关 3 秒周期遥测；事件和最终记录始终输出
- `X` 紧急停止

手动菜单：

- `1/2/3/4`：前/右/后/左
- `G`：1/2/3/4 格
- `S`：速度 100/120/150
- `N`：重复 1/3/5/10 次
- `L`：FREE/BOX/BOMB 载荷标签
- `R`：只跑一次
- `A`：自动重复，每段都停车确认视觉
- `C`：故障暂停后重试当前段
- `K`：把当前失败段标记跳过

自动菜单：

- `1/2/3`：QUICK12/STANDARD60/FULL180
- `R`：启动
- `P`：安全暂停
- `C`：重试当前格并继续
- `K`：跳过失败格并继续
- `S`：打印状态和最后记录

## 6. 输出格式

每个动作结束后输出：

- `CAL_REC`：会话、序号、路线、步号、是否有效、故障原因
- `CAL_CFG`：方向、格数、速度、载荷、电压、耗时、采样数
- `CAL_VISION`：视觉起终点、角度、frame_id、位置包计数、稳定帧
- `CAL_DELTA`：编码器/视觉纵横位移、目标误差、视觉与编码器差
- `CAL_ODOM`：三轮累计脉冲、IMU/编码器航向和最大横偏
- `CAL_DRIVE`：三轮平均速度、平均 PWM、峰值 PWM

这些字段足以按“方向 + 速度 + 地图位置 + 电压 + 载荷”分桶，拟合比例修正和横向耦合；原始记录保留，暂时不在车上直接学习，避免错误样本污染控制参数。

## 7. 安全状态流

正常单格：

`WAIT_ORIGIN -> RUNNING -> INTER_STEP -> WAIT_ORIGIN/COMPLETE`

其中底层 point_test 会经历：

`READY -> RUNNING -> SETTLING -> VIS_DRAIN -> VIS_STABLE -> DONE`

故障时进入 `PAUSED`，电机锁定，默认重试当前格。只有人工按 `C` 才重试，按 `K` 才跳过，按 `X` 才中止整次采集。

## 8. 首次实车测试流程

首次只跑 QUICK12，不直接跑 STANDARD60/FULL180：

1. 摄像头和 MCU 一起上电，车放在地图中部，前后左右至少留 1 格空间，保持静止约 3 秒。
2. 串口确认 `id=7100893`、`stage=TRACK_CAL_AUTO_UART`、`debug=3`、`display=OFF`、`VISION CONNECTED`。
3. 发送 `Z`，必须看到 `CAL ORIGIN verified`，且 `CAL_POINT` 中 `stable=1/6` 以上（实际应为 `1` 和 `6`）。
4. 先做 10 秒静止测试：`3 -> 1`。等待 COMPLETE，保存 `CAL_STILL`。
5. 返回主菜单：`B`。
6. 启动 QUICK12：`2 -> 1 -> R`。
7. 运行中不发其他命令；异常时先发 `S` 保存状态，再决定 `C` 重试或 `X` 停止。
8. QUICK12 完成后发送 `S`，保存从启动到 COMPLETE 的整段串口文本。

完整按键串：

```text
上电静止3秒 -> Z -> 3 -> 1 -> 等待完成 -> B -> 2 -> 1 -> R -> 等待完成 -> S
```

通过 QUICK12 后才跑 STANDARD60：重新上电并把车放在地图中部，四周至少留 2 格，然后：

```text
上电静止3秒 -> Z -> 2 -> 2 -> R
```
