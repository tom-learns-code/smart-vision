# 7100895 赛道采集目标与起步堵转保护

更新时间：2026-07-19

## 1. 采集的最终目的

模式3不是长期独立运行的调参程序，也不是为了无限增加样本。它只服务于正式完赛链路：

1. 求解器把路径拆成一个格一个格的动作。
2. 每格先由编码器执行约200mm主体位移，IMU在短时间内锁定航向。
3. 停车后保持500ms，排空约1000ms上游延迟画面，再等待多帧稳定视觉。
4. 视觉只有满足`car_valid`、多帧稳定和“靠近编码器预测位置”的门控时，才允许校正或重置融合位置。
5. 视觉无效、离群或超时，不得把车瞬移到错误位置；保留编码器/IMU预测并锁车或降级。
6. 全部动作结束后请求多帧FULL_MAP复核；若仍有未完成箱子，再从可信车位动态重规划。

采集数据最终用于建立方向、距离、赛道位置相关的修正表或低阶模型，比较编码器位移、IMU航向、延迟稳定视觉坐标、三轮计数/PWM和负载。第一目标是可靠完赛，不是连续高速、EKF或极限PID。

## 2. 已经得到的结论

- 一格均值：前200.8mm、后196.5mm、右178.0mm、左166.8mm。
- 两格均值：前411.6mm、后399.4mm、右385.0mm、左374.6mm。
- 三格合并均值：前606.5mm、后611.8mm、右588.2mm、左575.4mm。
- 误差没有随格数同比放大，CPR4096和里程比例0.915不是当前主因；方向相关的固定起停/制动偏差更明显。
- 原样的一格、两格、三格自动路线已经完成，禁止再次把GRID2_12或GRID3_12当常规测试重复运行。
- 两次长停都出现在左移低轮速起步，轻推后恢复。日志未撞10000最终PWM上限，支持静摩擦/驱动死区而非软件主动关驱动。
- 带人工推动的段只可谨慎参考最终距离，不得用于耗时、PWM、PID或起步模型拟合。

## 3. 7100895代码变更

当前MCU识别号：`7100895`；当前模式：`CONTROL_DEBUG_ENABLE=3U`；视觉端未修改，仍为`oa_id=7100422`。

### 通用堵转保护

- 平移开始后先留300ms起步宽限。
- 之后任意连续1000ms内，沿目标方向进度不足5mm，立即进入`POINT_FAULT_STALL`并锁车。
- 正式模式0、点测模式2和采集模式3都具备堵转保护。
- 该保护不会提高或限制正常速度，也不会等待原来的长超时。

### 仅模式3启用的起步补偿

- 起步窗口300ms，正式模式0和点测模式2保持关闭。
- 只对“目标非零且实测轮速绝对值不超过5”的轮子提供最小有效PWM。
- 后轮/左前/右前最小绝对PWM暂为`3000/2100/2200`，符号严格跟随各轮目标符号。
- 原PID、速度120、CPR4096、0.915、统一50mm制动提前量均未修改。

### 新增记录

`POINT_STATUS`和`CAL_POINT`增加：

```text
assist=启用/活动 mask=0x.. left=剩余ms stall=窗口ms/窗口进度mm
```

每一步最终`CAL_DRIVE`固化：

```text
assist_mask=0x.. assist_samples=.. stall=..ms/..mm
```

`assist_mask`是本次300ms窗口内曾触发过的粘滞标记，动作结束才清零；因此即使补偿只在最初5ms发生，也不会被20ms采集或3秒遥测漏掉。`assist_samples`表示窗口仍活动且已经发生过补偿的20ms采样数。

## 4. 模式3完整菜单

主菜单：`1`手动采集，`2`自动路线，`3`静止稳定性，`4`五帧FULL_MAP一致性，`5`设置，`6`摘要/最后记录，`Z`建立稳定视觉原点，`T`开关3秒遥测，`X`急停，`H`重印。

手动菜单：`1/2/3/4`为前/右/后/左；`G`循环1/2/3/4格；`S`循环速度100/120/150；`N`循环重复1/3/5/10次；`L`循环FREE/BOX/BOMB；`R`执行一次；`A`自动重复；`C`重试；`K`跳过；`P`状态和最后记录；`B/X/H`。

自动菜单：`1` QUICK12，`2` GRID2_12，`3` GRID3_12，`4` LENGTH36，`5` STANDARD60，`6` FULL180；`R`启动，`P`暂停，`C`继续/重试，`K`跳过，`S`状态，`B/X/H`。

静止菜单：`1`采10秒，`2`采30秒，`P`结果。FULL_MAP菜单：`1`采五帧，`P`结果。设置菜单保留速度、格数、重复、负载、电压标签配置。

## 5. 后续采集计划和停止条件

### 阶段A：只验证左移起步补偿

先做一次左移一格，不跑自动长路线。若无需手推且DONE，随后再做两次独立左移一格；连续三次均自主起步才通过。若仍失败，等待软件自动在约1秒报`STALL`，不要手推，根据`assist_mask/samples`只调整起步最小PWM。

### 阶段B：方向制动提前量

起步通过后，按现有一/二/三格数据先采用保守候选值：前50mm、后47mm、右30mm、左20mm。实装后只运行一次QUICK12作为四方向复验，不再跑GRID2_12/GRID3_12。实车一格误差在约2至3cm内且无明显航向累积即可接受，不追求厘米级外观完美。

### 阶段C：采地图位置修正表

在地图中心、中间环带和边缘代表位置采集停车后的稳定视觉残差。每条记录保留方向、区域、编码器预测、稳定视觉、IMU航向、横向误差、负载和电压。优先生成“四方向 x 中心/中间/边缘”的小表；边缘视觉若明显变暗，只降低权重或拒绝，不强行拟合。每个代表组合约3个有效样本即可，已有可复用记录不重采。

停止采集条件：

1. 左移连续三次自主起步，无堵转、无需手推。
2. 四方向单格复验误差可接受，航向不会逐格明显累积。
3. 停车后的稳定视觉能通过门控，异常视觉会被拒绝。
4. 简单方向/区域修正模型能降低编码器预测与稳定视觉的残差。

满足以上条件后立即停止模式3采集，切回模式0，不继续为连续运动、EKF、高速或漂亮曲线拖延完赛测试。

### 阶段D：回到正式全图

顺序固定为：空地图逐格前后左右 -> 空地图多动作 -> map2逐格完整Action -> 完赛后FULL_MAP复核 -> 未完成箱子动态重规划。炸弹/N-2观察算法在基础推箱链路稳定后接入；连续运动、EKF、逐轮PID精调和高速运行放在最后。
