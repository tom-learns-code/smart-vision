## 1. 整轮固定航向参考

- 每轮基地运动开始时保存该轮IMU基准。
- 出基地、获得非空地图并取得6帧/200ms稳定视觉簇后，只使用稳定视觉角度确定地图最近的90度主方向。
- 形成一次性的`round_imu_heading + round_map_heading + round_visual_heading`参考帧。
- 本轮后续求解、任务重新武装、运行时重规划、直线返航和BFS返航都只恢复这一份参考，不再用已经偏斜的实时车身方向重新定零。
- 新一轮比赛才清除并重新建立参考。
- 串口`MATCH_HEADING`会输出`fixed/imu/map/visual`，重规划前后这些值应保持不变。

这仍然允许IMU航向环实时纠偏；固定的是目标参考，而不是禁止控制器修正。

## 2. 节点化多格运动

### 档位边界

- SAFE：保持逐格，作为稳定回退档。
- NORMAL：当前仍保持逐格，先用于对照。
- FAST：允许节点合并，最长13格。

### 合并条件

连续步必须同时满足：

- 位于同一个`ACTION_FREE_MOVE`；
- 方向完全一致；
- 当前步与下一步均不在箱子、炸弹或目标点八邻域；
- 不是推箱、推炸弹、观察、等待或阶段切换；
- 不跨越单边墙关系、走廊轴或环境上下文切换；
- 每次按`mission_expected_map`重新计算，推动后的动态物体位置会立即参与后续判断。

因此进入物体八邻域、八邻域内部、离开八邻域的最后一步均保持逐格强矫正；推箱和炸弹始终逐格。

### n格直线的执行

- `n=1`：原逐格逻辑。
- `n=2`：直接完成2格，在节点进行强矫正。
- `n>=3`：先巡航`n-1`格，仅做航向锁定和有界横向修正；停车获得稳定视觉后，以真实剩余位移执行终端节点阶段，而不是盲目固定再走200mm。
- 终端允许280mm起点误差和300mm有界二维回拉。若巡航因惯性略微越过节点，不会因前向投影为负而永久等待，而是二维回拉到节点。
- 每个合并终点、转弯点、物体八邻域边界和推物步骤仍是节点；节点完成才推进动作游标。

遥测字段：

- `MISSION_EXEC phase=SINGLE/CRUISE/TERMINAL total=... cruise=... node=(x,y)`
- `RUN_TELEM seg=phase/cruise/total node=(x,y)`
- `RUN_VIS cruise=... terminal=... max=... start_tol=...`

## 3. B11非阻塞蜂鸣器

引脚固定为`B11`，推挽输出，低电平静音、高电平响。业务状态机只投递事件；现有PIT 5ms中断推进引脚和时序，不使用`delay`，不在主循环等待，也不改变电机5ms控制周期。

所有时间集中在`project/code/status_buzzer.h`：

- 上电：1000ms。
- 每个有效串口菜单命令：200ms。
- 准备启动车辆：1000ms。
- 发起地图请求：500ms。
- 路径解算完成：500ms。
- 到达节点：200ms。
- 进入锁车/故障/暂停重规划：1000ms。
- 强矫正：200ms响、400ms停、200ms响。

UART上电偶发的`0x00`空字节不会触发菜单短鸣，只有可打印指令字符才计为命令。

事件队列为16项。锁车事件具有最高优先级，会清空普通待响队列并立即长鸣；队列溢出次数由`buzzer_drop`输出。

## 5. 实车验收顺序

### A. SAFE回归（先守住稳定底线）

完整断电、下载新AXF并重启。启动应先响1秒，终端应显示`id=7100953`。进入完整比赛菜单：

`6 -> 1 -> C -> 4/5/6/7 -> 1 -> P -> Q -> A -> S -> V -> Y`

- `4/5/6/7`只选现场安全出口。
- `1`在配置菜单设速度100。
- 回到完整比赛菜单后确认标题为`profile=SAFE`；若不是SAFE，按`P`循环到SAFE后再`A`。
- `A`只武装不动车；`S`查看状态；`V`要求`ready=0x03/0x03`；`Y`才启动车。
- 验收一张图完整执行、物体八邻域强矫正、推物与返航。该档行为不使用节点合并。

### B. FAST节点批量验证

重新断电上电后进入：

`6 -> 1 -> P -> P -> C -> 5 -> 2 -> P -> Q -> A -> S -> V -> Y`

默认SAFE时按两次`P`到FAST；若标题不是FAST，继续按`P`循环确认。选择一张含至少3格开阔直线且物体邻域清晰的地图。

正常现象：

- 开阔同一直线出现`phase=CRUISE total=n cruise=n-1`，随后`phase=TERMINAL`。
- 合并直线中间不再逐格停顿；最终节点停车、视觉稳定并强矫正。
- 箱子/炸弹/目标八邻域显示`total=1 strict=1`，仍逐格。
- 每个节点短响一次，强矫正双响；不能连续无意义狂响。
- 发生运行时重规划后，`MATCH_HEADING`中的固定三项不变。

若FAST出现异常，立即`X`，长鸣1秒后电机锁定；下次上电改回SAFE继续，不影响稳定回退版本。
