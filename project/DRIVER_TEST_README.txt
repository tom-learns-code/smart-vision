==================================================
           RT1064 驱动测试程序
==================================================

【功能说明】
本程序用于测试RT1064板子的基本驱动是否正常工作

【测试项目】
1. GPIO测试 - LED闪烁
2. UART测试 - 串口通信和回显

【硬件连接】
- 测试LED：连接到D0引脚（已通过LED焊接）
- 串口通信：使用DEBUG串口（UART_1）

【测试步骤】
1. 编译工程并下载到板子
2. 打开串口调试助手（波特率115200）
3. 观察串口输出和LED状态

【预期结果】
1. 串口输出欢迎信息
2. LED闪烁5次（ON/OFF交替）
3. 进入串口回显模式
4. 发送任意字符，串口应回显该字符
5. 心跳LED每2秒翻转一次
6. 连续按3次ESC键退出测试
7. LED常亮，测试完成

【故障排查】
- 如果LED不闪烁：检查D0引脚焊接和LED连接
- 如果串口无输出：检查DEBUG串口连接和波特率设置
- 如果程序不运行：检查电源和下载是否成功

【文件说明】
- main.c: 主测试程序
- driver_test.c: 扩展测试程序（可选）
- isr.c: 中断处理函数

【注意事项】
1. 确保板子电源正常
2. 确保DEBUG串口已连接到电脑
3. 串口调试助手波特率设置为115200
