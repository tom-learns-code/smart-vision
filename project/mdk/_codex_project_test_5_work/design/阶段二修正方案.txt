================================================================================
  阶段二修正方案 —— 规避节点 + 安全连线图（终版 v2）
  2026-06-01
================================================================================

背景:
  原阶段二采用的 LOS 路径平滑（Bresenham 细线 → 动态扫过宽度距离判定）在
  墙体密集的 16×12 竞赛地图中几乎无法产生捷径，因为固定阈值无法同时适应
  "开阔地带可行斜穿"和"墙边必须保守"两种需求。

  本方案将"能不能斜走"从一个局部几何问题变为全局结构分析问题：
  预计算所有"碰撞热点"（规避节点）→ 构建安全连线图 → 统一混合图上 Dijkstra 自动选捷径。

================================================================================
一、规避节点
================================================================================

1.1 定义

  一个可行走格点 P 是规避节点，当且仅当三个条件同时满足：
    (a) P 的 4 个对角邻域中，至少 1 个是障碍物（墙体或物体）
    (b) P 的 4 个相邻邻域（上下左右）中，至少 2 个是无障碍的
    (c) 存在满足(a)的对角障碍物 D，D 与 P 共享的 2 个相邻格
        （D 的水平和垂直方向邻格，即到达 P 需经过的两格）都无障碍
        —— D 必须是一个"凸角"，而非平直墙面

  条件(b)过滤死胡同和不可达格子。
  条件(c)过滤平直墙面两侧的格子（不是真正的凸角热点）。

1.2 物理含义

  规避节点标记的是墙/物体凸角（末端）的对角格子——车斜穿时最容易撞墙的位置。
  显式提取后，这些节点成为：
    - 碰撞热点 → 路径规划时中心线不能从它们上面碾过
    - 捷径锚点 → 作为捷径边的端点
    - 中心线阻断器 → 防止捷径从另一个规避节点头上飞过

1.3 示例

  ┌───┬───┬───┬───┬───┐
  │   │   │ P │   │   │    # # # 为墙体
  ├───┼───┼─┼─┼───┼───┤    P 为规避节点
  │   │ # │ # │ # │   │    P 的 NW对角 D=(1,1)=墙
  ├───┼───┼─┼─┼───┼───┤    D 的2个共享相邻格(0,1)(1,0)都自由 → D是凸角
  │   │   │ P │   │   │    P 4个相邻中(0,0)越界(1,0)自由(0,1)自由(2,0)??
  └───┴───┴───┴───┴───┘    → 至少2侧自由 → P是规避节点 ✓

1.4 物体规避节点

  物体自身也视为障碍物，其周围同样按规则产生规避节点。
  与软障碍区（8邻域）同步更新与失效。

================================================================================
二、安全连线判定
================================================================================

2.1 两重判定

  任意两个 walkable 格点 A 和 B 之间存在安全连线，需同时满足两个条件：

  条件一：中心线干净
    Bresenham 遍历 A→B 中心连线（网格级），不穿过：
      · 墙体
      · 物体自身格
      · 其他规避节点（避免 A→C→B 和 A→B 同时存在）

  条件二：4 角连线不碰墙
    车体 1×1 正方形从 A 中心移到 B 中心，扫过区域的 4 条角边界线
    （±0.49 偏移量）都不穿过任何墙体。

    4 条角线：
      (ax-0.49, ay-0.49) → (bx-0.49, by-0.49)   左上
      (ax+0.49, ay-0.49) → (bx+0.49, by-0.49)   右上
      (ax-0.49, ay+0.49) → (bx-0.49, by+0.49)   左下
      (ax+0.49, ay+0.49) → (bx+0.49, by+0.49)   右下

    0.49 偏移（略内缩 0.01）避免 Bresenham 浮点在格边界上的误判。

  无距离过滤 —— 相邻规避节点（包括同行同列）通过两条检验即为捷径边。

2.2 物理含义

  条件一（中心线）: 防止规避节点共线。A→B 中心线穿过 C → 不安全 → 只能 A→C, C→B。
  条件二（4角连线）: 车体扫过区域的 4 条边界不碰墙 → 内部也不会碰墙。

================================================================================
三、软障碍区
================================================================================

  每个物体（箱子/炸弹）周围 8 邻域（不含墙和物体自身格）= 软障碍区。
  车在此区域内接近物体时，需要更谨慎的路径规划。

  重叠区中一个格点可以同时属于多个软障碍区（数学集合的常规行为）。

================================================================================
四、MOVING 状态分类（每条边独立判定）
================================================================================

  MOVING = 所有非推物体阶段（PUSHING 走格子不变）

  对 Dijkstra 途中的每条候选边，独立判定其分类：

    捷径边两端在同一软障碍区 → 禁用该捷径边（按 unfree 处理）
    其他所有情况                → free，允许捷径

  整段路径中每条边独立判定，Dijkstra 在各区之间平滑过渡。

================================================================================
五、统一混合图
================================================================================

5.1 图结构

  一张图，三种边混合，Dijkstra 自动选优：

  ┌──────────────┬──────────────────────────────────┬────────────┐
  │ 边类型       │ 条件                             │ 代价       │
  ├──────────────┼──────────────────────────────────┼────────────┤
  │ 捷径边       │ 两规避节点安全连线               │ 欧氏距离   │
  │              │ 且不同时在同一软障碍区           │            │
  ├──────────────┼──────────────────────────────────┼────────────┤
  │ 格线（软区） │ 4 邻接，两端在软障碍区           │ 1          │
  ├──────────────┼──────────────────────────────────┼────────────┤
  │ 格线（开放） │ 4 邻接，至少一端在开放区         │ 10         │
  └──────────────┴──────────────────────────────────┴────────────┘

  Dijkstra 自动行为：
    - 开放区：捷径便宜（~1.4-5），格线贵（10/步）→ 优选捷径
    - 软障碍区：格线便宜（1），捷径被禁 → 走格子
    - 贴墙离开：走 1-2 步开放区格线（10-20），到达规避节点后切捷径

5.2 车当前位置

  每次 free_move 开始时：
    - 车在缓存规避节点上 → 直接复用图
    - 车不在 → 临时规避节点 + 只计算它到各规避节点的捷径边（增量，O(N)）
    - free_move 结束后临时节点失效

5.3 退化兼容

  如果没有规避节点或没有安全连线：
    - 图只剩格线边（软区代价1，开放区代价10）
    - Dijkstra 退化为带权 BFS
    - 与阶段一的纯格线路径一致 → 零退化风险

================================================================================
六、生命周期
================================================================================

6.1 开局预计算

  1. walls → 墙体规避节点 + 全对安全连线（缓存）
  2. set_objects(box_positions) → 物体规避节点 + 软障碍区 + 增量更新连线
  3. set_car(car_start) → 临时规避节点 + 到网络的捷径边

6.2 每次 free_move

  1. 车在缓存规避节点上 → 复用图
     车不在 → 临时规避节点 + 增量计算到各规避节点的捷径边
  2. 构建统一混合图 → Dijkstra → waypoints
  3. 物体未移动 → 缓存复用，跳过图重建

6.3 推箱拐点（move_object）

  1. 旧箱位 → 移除规避节点和软障碍区
  2. 新箱位 → 生成规避节点和软障碍区
  3. 增量重算受影响的捷径边

6.4 箱子到目标（remove_object）

  1. 立即清除该箱的规避节点和软障碍区
  2. 重算受影响捷径边

================================================================================
七、与阶段一的退化兼容
================================================================================

  如果地图没有规避节点（极其罕见），或所有连线都不安全：
    - 统一混合图只剩格线边
    - Dijkstra 退化为带权 BFS（开放区代价10，软区代价1）
    - waypoint 序列和阶段一基本一致（代价权重不同但不影响最短路径）
    → 零退化风险
