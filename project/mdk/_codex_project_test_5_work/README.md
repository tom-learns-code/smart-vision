# 车推箱子物理引擎

一个基于 Pygame 的 2D 物理引擎模拟，实现车辆推动箱子、炸弹爆炸、目标点收集等物理交互。

## 功能特性

- **车辆控制**：使用 WASD 移动车辆，Q/E 旋转车辆
- **物理碰撞**：SAT 碰撞检测、轴对齐法线、穿透修正
- **多种物体**：
  - 车辆：可控移动和旋转
  - 箱子：可被推动，支持无阻力推动模式
  - 炸弹：推入墙内后炸毁 3x3 区域内的墙体
  - 目标点：箱子到达后触发收集
  - 墙体：静态障碍物，可被编辑
- **编辑模式**：支持墙体编辑和自定义关卡
- **速度档位**：4 档速度可调（慢速、普通、快速、极速）
- **无阻力模式**：车推动物体时消除摩擦力，支持链式推动

## 安装依赖

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install pygame
```

## 运行项目

### Windows

双击 `run.bat` 启动游戏

### 跨平台

```bash
python main.py
```

## 操作指南

| 按键 | 功能 |
|------|------|
| W / S | 前进 / 后退 |
| A / D | 左转 / 右转 |
| Q / E | 旋转车身 |
| 1 / 2 | 切换速度档位 |
| 空格 | 重置游戏 |
| Tab | 切换编辑模式 |

## 编辑模式

在编辑模式下：
- **鼠标左键**：放置/删除墙体
- **鼠标右键**：放置炸弹
- **ESC**：退出编辑模式

## 技术特性

- **SAT 碰撞检测**：分离轴定理精确检测任意多边形碰撞
- **轴对齐法线**：将碰撞法线投影到水平/垂直方向，消除伪切向速度
- **自适应子步数**：根据碰撞强度动态调整物理子步数
- **空间哈希**：优化碰撞检测性能
- **多级管道**：分离检测 -> 响应 -> 修正，避免循环依赖
- **双向碰撞检测**：物体间碰撞双向处理，减少纠缠现象
- **无阻力推动**：车推物体时消除摩擦力，支持长链式推动

## 物理参数

主要参数可在 `core/config.py` 中调整：

```python
SCREEN_WIDTH = 1200        # 屏幕宽度
SCREEN_HEIGHT = 800        # 屏幕高度
FPS = 60                   # 帧率
BASE_SUBSTEPS = 10         # 基础物理子步数
OBJECT_SIZE = 40           # 物体大小（像素）
```

## 开发说明

### 扩展新物体类型

1. 在 `core/` 下创建新类文件
2. 继承 `GameObject` 或 `Player`
3. 在 `game_factory.py` 添加创建方法
4. 在 `main.py` 的游戏循环中集成

### 自定义关卡

1. 运行游戏后按 `Tab` 进入编辑模式
2. 使用鼠标绘制墙体布局
3. 放置炸弹和目标点
4. 按 `ESC` 退出编辑模式
