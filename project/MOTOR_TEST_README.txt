==================================================
           RT1064 电机驱动测试程序
==================================================

【功能说明】
本程序用于测试RT1064板子的电机驱动是否正常工作

【测试项目】
1. LED闪烁测试 - 验证程序运行
2. 单个电机测试 - 逐个测试4个电机
3. 所有电机测试 - 同时测试所有电机
4. 麦轮运动测试 - 测试麦轮运动模式

【硬件连接】
- 电机PWM输出引脚：
  - 左前轮(LF): D12 (PWM1 Module 0 Channel A)
  - 左后轮(LB): D13 (PWM1 Module 0 Channel B)
  - 右前轮(RF): D14 (PWM1 Module 1 Channel A)
  - 右后轮(RB): D15 (PWM1 Module 1 Channel B)

- 测试LED：D0引脚
- 串口通信：UART_1（DEBUG串口）

【测试步骤】
1. 编译工程并下载到板子
2. 打开串口调试助手（波特率115200）
3. 观察LED闪烁3次
4. 按任意键开始电机测试
5. 观察电机运行情况

【测试详情】
========================================
Test 1: 单个电机测试
========================================
依次测试4个电机，每个电机运行以下占空比：
- 0%  (停止)
- 25% (低速)
- 50% (中速)
- 75% (高速)
- 100% (全速)
每个占空比运行2秒

测试顺序：
1. 左前轮 (LF)
2. 左后轮 (LB)
3. 右前轮 (RF)
4. 右后轮 (RB)

========================================
Test 2: 所有电机测试
========================================
同时运行所有电机，测试占空比：
- 25% (3秒)
- 50% (3秒)
- 75% (3秒)
- 停止

========================================
Test 3: 麦轮运动测试
========================================
测试麦轮车的基本运动模式：
- 向前移动 (2秒)
- 向右移动 (2秒)
- 顺时针旋转 (2秒)

【预期结果】
1. 串口输出测试信息
2. LED闪烁3次表示程序运行
3. 按任意键后开始电机测试
4. 每个电机能正常启动和停止
5. 电机速度随占空比变化而变化
6. 测试完成后LED每2秒闪烁一次

【注意事项】
1. 测试前确保电机已正确连接到驱动板
2. 测试前确保电机驱动板已上电
3. 建议将车模架空进行测试，避免意外移动
4. 电机占空比从低到高逐步增加，观察电机响应
5. 如果电机不转，检查：
   - PWM引脚是否正确连接
   - 电机驱动板是否供电
   - 电机驱动板使能信号是否正确

【故障排查】
1. 串口无输出：检查DEBUG串口连接
2. LED不闪烁：检查程序是否下载成功
3. 电机不转：
   - 检查PWM引脚连接
   - 检查电机驱动板供电
   - 检查驱动板使能信号
   - 使用示波器测量PWM波形
4. 电机转速不对：
   - 检查PWM频率设置
   - 检查占空比计算

【PWM参数】
- PWM频率：10kHz
- PWM占空比范围：0 ~ 10000 (0% ~ 100%)
- PWM分辨率：10000级

【串口设置】
- 波特率：115200
- 数据位：8
- 停止位：1
- 校验位：无

【安全提示】
1. 测试时请将车模架空，避免意外移动
2. 确保电机驱动板电源充足
3. 注意电机温度，避免长时间高占空比运行
4. 测试过程中随时可以复位板子停止电机
